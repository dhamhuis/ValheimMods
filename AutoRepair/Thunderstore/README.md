# AutoRepair

Author: dhamhuis

When you open a usable crafting station, AutoRepair repairs eligible items in your inventory using Valheim's own repair checks. Gear remains subject to the station's normal level limits.

## Requirements

- Valheim
- BepInExPack_Valheim

Install through r2modman or place `AutoRepair.dll` in `BepInEx/plugins/AutoRepair`.

Issues and source: https://github.com/dhamhuis/ValheimMods
